# 焦亚峰 · AI运营求职作品集

一个可直接部署的静态网站。手机、电脑均可打开，无需任何服务器。

## 本地预览

直接双击 `index.html`，或在本文件夹内运行任意静态服务器。

## 网站内容

- 首页：姓名、学校、求职方向、联系方式（已填好）
- 四段项目经历：签约长篇小说 / 抖音与视频号矩阵 / 餐饮商家物料 / 网页小游戏 v2.8
- 「下载简历」按钮：附带 `简历.pdf`（与投递的简历同一版）
- 所有图片已压缩（共约 1.7MB），手机流量打开也快
- 内容只写现有材料能核对的事实，未编造数据

## 投递前检查

1. 换手机、退出登录状态，打开网址测试一次：字能不能看清、图片能不能加载、按钮能不能点；
2. 简历和作品集说法一致（时间、数字、职责）；
3. 每投一个岗位，把最匹配的项目移到最前面。
